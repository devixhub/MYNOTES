                                            JENKINS WINDOWS AGENT (NODE) SETUP
                       CONFIGURE A WINDOWS MACHINE AS A JENKINS AGENT AND RUN FREESTYLE MAVEN JOBS.
Step 1
Manage Jenkins ->Nodes -> New Node-> Name: windows-node->Permanent Agent-> Create.
Configure Remote Root Directory (path of your desktop folder), Label (win_slave), Usage: Use this node as
much as possible, Launch method: Launch agent by connecting it to the controller, Save.

step-2
go to security ->agents ->TCP port for inbound agent ->random

Step 3
Open the node and click windows-node copy the code for window first command run, then run the second  command
on the Windows machine you created by going to cmd mode. Verify node status becomes Online by refreshing

step 4
Configure JDK in Manage Jenkins ->Tools ADD JDK: JAVA_HOME_WIN. Java Home: C:\Program
Files\Java\jdk-21 (PATH AVILABLE IN WINDOWS ENVIROMENT VARIABLE)
Configure Maven in Manage Jenkins → Tools ADD Name: M2_HOME_WIN. Maven Home: C:\Program
Files\Apache\Maven.(PATH AVILABLE IN WINDOWS ENVIROMENT VARIABLE)

Step 5
Create a Freestyle Project named WIN-JOB.
Enable 'Restrict where this project can be run' and enter label 'win_slave'.
Configure Git repository URL: https://github.com/devixhub/git-maven-testing.git
configure jdk and maven path of window's ALREDY AVILABLE
Build Step: Invoke top-level Maven targets. Maven: M2_HOME_WIN. Goals:compile.
