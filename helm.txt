core components of Helm
----------------------------------------------------
Chart
Repository
Release
----------------------------------------------------
Chart->consider it is container image
Repository -> consider it is image registory
release ->consider it is running conatiner
----------------------------------------------------
->Repository is the place where you can store the chart
->Release is the running instance of chart
----------------------------------------------------
CHART
----------------------------------------------------
->It contains everything you need to deploy an application
->Includes templates, values, and metadata(like a config bundle)
->Reusable, versioned blueprint of your app
->Can be shared via chart repositories or reused across env
----------------------------------------------------
REPO
------------------------
->stores and shares versioned helm charts
->you can add multiple repos and search across them
->popular ones include bitnami, Truecharts, grafana.
->charts from many repos are indexed on artifacthub.io
->use helm repo add, list, search repo to interact
----------------------------------------------------
RELEASE
------------------------
->A running instance of a chart in your cluster
->Created with helm install <relase-name>
->Each release has its own config,history,and state
->Can be upgrade, rolled back or uninstalled
->Same chart can be installed multiple times as different release (app1-dev,app1-prod, etc))
------------------------
Repository->containes->charts->installed as->releases

------------------------
Binary
------------------------
# Download Helm binary
wget https://get.helm.sh/helm-v3.19.0-linux-amd64.tar.gz

# Extract the downloaded file
tar -zxvf helm-v3.19.0-linux-amd64.tar.gz

# Move Helm binary
sudo mv linux-amd64/helm /usr/local/bin/helm

# Verify Helm installation
helm version
