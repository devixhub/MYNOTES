>mvn compile -----(3)
mvn compile
      │
      ▼
1. Read pom.xml
      │
      ▼
2. Validate project
      │
      ▼
3. Check .m2/repository for dependencies/create target folder
      │
      ▼
4. If missing → Download from Maven Central
      │
      ▼
5. Store dependencies in .m2/repository
      │
      ▼
6. Compile .java files
      │
      ▼
7. Generate .class files in target/classes


>>mvn test  ----(4)
mvn test
      │
      ▼
1. validate
      │
      ▼
2. compile (main source code)
      │
      ▼
3. Compile test source code
      │
      ▼
4. Run JUnit/TestNG test cases
      │
      ▼
5. Surefire Plugin generates test reports
      │
      ▼
6. Build PASS or FAIL

>mvn package -----(5)
mvn package
      │
      ▼
1. validate
      │
      ▼
2. compile (.java → .class)
      │
      ▼
3. test (Run JUnit/TestNG tests)
      │
      ▼
4. package (.class → JAR/WAR)
      │
      ▼
5. Store JAR/WAR in target/
it will created app-1.0.jar in target folder.
>> mvn install ----(6)
mvn install
      │
      ▼

      │
      ▼

      ▼

      ▼
